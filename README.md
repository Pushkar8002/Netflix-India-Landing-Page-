# Netflix India Landing Page 🎬

A responsive **Netflix India landing page clone** built using **HTML and CSS**. This project recreates the Netflix homepage layout with a hero section, subscription form, feature sections, FAQ section, and footer.

### Features

* Netflix-style homepage design
* Responsive layout
* Hero section with email input
* TV, mobile, and device sections
* FAQ section
* Footer with useful links
* HTML5 and CSS3

### Technologies Used

* HTML
* CSS
* SVG
* HTML5 Video


This project was created for **learning and practicing frontend web development**, especially HTML structure, CSS styling, layouts, and responsive design.
